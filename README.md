# Zenith Amman: Website Redesign Concept

A mobile-first, bilingual (English / Arabic) redesign concept for Zenith Grill & Lounge, 17th floor of The St. Regis Amman.

This is an independent design concept prepared for presentation. It is not affiliated with or published on behalf of Zenith, The St. Regis Amman or Marriott International. Photography and copy are taken from the venue's current public website for presentation only.

Static site: open `index.html`. No build step.
